# Spillmark

Spillmark connects AI clients to Amazon seller math over MCP. The public server answers profit, fee, ACoS, TACoS and holdout sizing questions with no API key, and a brand key reads one brand's profit and incrementality record.

## Connect

- Remote MCP (Streamable HTTP): `https://spillmark.com/mcp`
- Free Amazon Ads MCP Checker: https://spillmark.com/tools/amazon-ads-mcp-checker
- MCP guide: https://spillmark.com/uses/amazon-ads-mcp
- Privacy policy: https://spillmark.com/privacy
